Private by design

Privacy isn’t a setting.
It’s the architecture.

Cloud “AI search” understands what you mean — after you upload your notes, contracts, research papers and meeting recordings to somebody else’s server. Soma keeps all of it, and all of the intelligence, here.

Nothing is uploaded

Indexing, embedding, reranking and searching all happen on-device. There is no telemetry, no account and no background daemon you didn’t ask for.

No API keys

Soma bundles a local inference stack — llama.cpp and whisperfile — and downloads open-weight models. No OpenAI key. No subscription.

Air-gap ready

Export every model and tool as one reproducible ZIP on a connected machine, then --import it on an isolated one. Zero HTTP at runtime.

Features

A full retrieval stack,
shipped as one file.

Hybrid search

Lexical BM25 + dense embeddings + a HyDE passage, fused with Reciprocal Rank Fusion and reranked by a local LLM. Best relevance, out of the box.

Still great at exact matching

Prefix matching, "quoted phrases", -exclusions and per-project scoping. BM25 ranked — fast, deterministic, no models involved.

Multilingual & CJK

Unicode NFKC normalization, camelCase / snake_case / path tokenization, plus CJK unigram + bigram indexing so 1–2 character queries still work.

Built-in web UI

soma server serves a single-file browser interface on localhost:8181 — search, projects, status and documents.

Agent-friendly

JSON / CSV / Markdown / paths output and a JSON-RPC-style POST /api/run endpoint that mirrors the CLI. One contract to learn.

Local models only

EmbeddingGemma for embeddings, QMD for query expansion, Qwen3 Reranker, Qwen3-VL for images and Whisper for speech — all via llama.cpp / whisperfile, on CPU or GPU.

Workspaces & context hints

Run soma init to keep config and index inside ./.soma/ so the index travels with the folder. Attach descriptive hints to a path to sharpen relevance and snippets.

Search modes

Trade recall for precision.
Or speed. Your call.

Best relevance

A local LLM expands your query into lexical keywords, dense retrieval sentences and a HyDE passage. Every signal is fused with RRF, then reranked locally. Override any channel by hand with --lex, --vec, --hyde, or add background with --intent.

$ soma search "how does auth work"

$ soma s "performance" --intent "web page load times"

$ soma search hybrid --lex "CAP theorem" \
                    --vec "consistency tradeoffs"

Exact keywords, phrases, exclusions

BM25 ranked, no embeddings, no LLM — fast and deterministic.

  • word — prefix match (perf → performance)
  • "phrase" — exact phrase
  • -word / -"phrase" — exclude
$ soma search lexical "CAP theorem consistency"

$ soma search lexical '"machine learning" -"deep learning"'

$ soma search lexical "auth -oauth -saml" --line-number

Pure semantic similarity

Embeds your query directly and searches by meaning — no expansion, no HyDE, no reranking. The leanest semantic path.

$ soma search vector "what happens when a pod crashes"

$ soma s v "login failures" --intent "auth troubleshooting"

Describe the answer you want

Write what a good matching document would say, and search with that. Great when you remember the shape of the answer but none of the words in the file.

$ soma search --hyde "The rate limiter uses a sliding window
  with a 60-second window. Clients exceeding 100 requests
  per minute receive 429 Too Many Requests."

All search and get commands support -f text|json|csv|md|paths — pipe straight into scripts, editors or AI agents.

Get Soma

One file. Zero setup.

A single GraalVM native binary. No Python, no Docker, no vector database service. Pick your platform.

# macOS (Apple Silicon) · Homebrew
$ brew install AwesomeDog/tap/soma
$ soma --version
# Windows x64 · winget
> winget install AwesomeDog.soma
> soma --version
# Linux x64 · single binary
$ curl -fsSL https://github.com/AwesomeDog/soma/releases/latest/download/soma-linux-x64 -o soma
$ chmod +x soma && sudo mv soma /usr/local/bin/
$ soma --version
# On a machine with internet
$ soma system pull --export soma-artifacts.zip

# On the air-gapped machine (no HTTP performed)
$ soma system pull --import soma-artifacts.zip

The export is reproducible — identical package hashes produce a byte-identical ZIP — and covers every supported platform.

Tech specs

Everything, in detail.

System requirements

  • RAM — 8 GB minimum for text search
  • RAM — 24 GB+ while multimedia features run (OCR, vision, transcription)
  • GPU — optional; speeds up embedding, vision and transcription
  • OS — Windows x64 · macOS ARM64 · Linux x64
  • Disk — space for models downloaded on first sync
  • Network — only for the first sync or system pull

Local model stack

  • Embeddings — EmbeddingGemma 300M
  • Query expansion — QMD 1.7B
  • Reranker — Qwen3 Reranker 0.6B
  • Generation / vision — Qwen3-4B-Instruct · Qwen3-VL 4B
  • Speech — Whisper (whisper.cpp releases)
  • Runtimes — llama.cpp · whisperfile

Index & tooling

  • Store — local SQLite, full-text + sqlite-vec vectors
  • Fusion — Reciprocal Rank Fusion
  • PDF / OCR — pdfium helper · RapidOCR-CLI
  • Docs — Pandoc (Office / EPUB → Markdown)
  • Media — FFmpeg / Jellyfin FFmpeg
  • Binary — GraalVM native image

Where Soma stores data

  • Config — $XDG_CONFIG_HOME/soma/<ws>.yml
  • Index DB — $XDG_STATE_HOME/soma/<ws>.sqlite
  • Cache — $XDG_STATE_HOME/soma/caches/
  • Logs / locks — $XDG_STATE_HOME/soma/{logs,locks}/
  • Models & tools — $XDG_DATA_HOME/soma/
  • Source files are never modified.

FAQ

Good questions.

Does Soma send anything to the cloud?
No. Indexing and searching are 100% local. The only network access is downloading models and CLI tools on first use (soma sync / soma system pull), which you can also do offline via --export / --import.
Do I need an OpenAI / Anthropic API key?
No. Soma bundles a local inference stack (llama.cpp, whisperfile) and downloads open-weight models.
Do I need a GPU?
No. Everything runs on CPU. A GPU mainly accelerates embedding, vision extraction and transcription.
Does it modify or move my files?
No. Soma reads your files and writes its index elsewhere. Your folders stay untouched.
Which languages does it support?
Indexing and querying are multilingual, with dedicated CJK handling (unigram + bigram indexing) so short Chinese, Japanese and Korean queries remain retrievable.
How is this different from ripgrep?
ripgrep matches literal strings and regexes in text files. Soma additionally understands meaning, and can search inside PDFs, Office documents, images, audio and video.
Can I use Soma as a RAG backend for an AI agent?
Yes — use -f json from the CLI or POST /api/run over HTTP. The API mirrors the CLI, so there is only one contract to learn.
Where does the index live, and can I move it?
By default under XDG state directories. Run soma init in a folder to keep config and index in ./.soma/, so the searchable index travels with the directory.
Something looks stale or broken. What do I run?
soma sync for the normal cycle, soma system scan for a full re-read of every file, soma status for diagnostics.
